**Геймплей:** Escape from Tarkov (рейдовая механика, система выживания, реалистичная баллистика).  
**Атмосфера:** S.T.A.L.K.E.R. (постапокалиптическая Зона, сталкерская романтика, аномалии).
**Наличие мультиплеера:** предусмотрен локальный кооператив. 

**Место действия:** г. Йошкар‑Ола и окрестности (Республика Марий Эл), превратившиеся в Зону после выброса «ЭХО».  

**Запретная зона:** ограничена объездной дорогой вокруг Йошкар‑Олы, включает посёлки Краснооктябрьский, Шойбулак и Цибикнур.  

**Хаб‑локация:** НИИ «ЭХО» в селе Ежово (на месте бывшего Ежовского аграрного колледжа).
